GUÍA DE IMPLEMENTACIÓN: SISTEMA DE CRIATURAS (ÁNGEL Y DEMONIO)

1. LIMPIEZA DE ARCHIVOS
   - Ve a la carpeta de tus scripts.
   - ELIMINA los archivos: "AngelHealer.cs" y "DemonShooter.cs".
   - Estos scripts ya no son necesarios, su lógica ha sido fusionada.

2. CONFIGURACIÓN DEL PREFAB ÁNGEL
   - Selecciona tu prefab o objeto "Angel".
   - Asegúrate de que tenga el componente [AngelCreature].
   - SI tiene el componente antiguo [AngelHealer], ELIMÍNALO (Remove Component).
   - En el inspector de [AngelCreature]:
     * Asigna el "Heal Effect" (Prefab de partículas de curación).
     * Asigna el "Heal Sound" (AudioClip de curación).
     * Configura "Heal Amount" (ej: 30) y "Heal Range" (ej: 5).
     * Verifica que la tecla sea Q (o la que prefieras).
   - NOTA: El ángel ahora es PACÍFICO. No atacará a nadie, solo curará al Player cuando presiones la tecla.

3. CONFIGURACIÓN DEL PREFAB DEMONIO
   - Selecciona tu prefab o objeto "Demon".
   - Asegúrate de que tenga el componente [DemonCreature].
   - SI tiene el componente antiguo [DemonShooter], ELIMÍNALO.
   - En el inspector de [DemonCreature]:
     * "Projectile Prefab": Arrastra tu prefab del proyectil aquí.
     * "Fire Point": Arrastra el objeto hijo desde donde salen los disparos (o déjalo vacío para usar el centro).
     * "Detection Range": Distancia para ver enemigos (ej: 8).
   - NOTA: El demonio ahora dispara 1 SOLO proyectil a la vez. No disparará de nuevo hasta que el actual impacte o desaparezca.

4. CONFIGURACIÓN DEL PROYECTIL
   - Selecciona tu prefab del proyectil.
   - Debe tener el componente [Projectile].
   - Asegúrate de que tenga un [Rigidbody2D]:
     * Body Type: Dynamic
     * Gravity Scale: 0
     * Collision Detection: Continuous
   - En el inspector de [Projectile]:
     * "Hit Effect": Asigna el prefab de explosión/impacto.
     * "Damage": Daño del impacto (ej: 25).
     * "Lifetime": Tiempo antes de destruirse solo (ej: 3).

5. RESUMEN DE CAMBIOS
   - Se eliminaron todos los comentarios y tooltips de los scripts para "humanizarlos".
   - Se unificó la lógica: menos scripts, mismo funcionamiento.
   - Se corrigieron las físicas del proyectil para ser más estables.
   - Se eliminaron todos los Debug.Log para limpiar la consola.
